## 要构建什么

为移动端“最近播放页”补充最小页面骨架和空态。没有最近播放歌曲时，页面应显示清晰、轻量的空态文案，而不是崩溃、白屏或留空。

## 验收标准

- [ ] 移动端“最近播放页”可以正常渲染。
- [ ] 最近播放列表为空时显示轻量空态文案。
- [ ] 空态说明播放歌曲后才会产生最近播放记录。
- [ ] 页面保留普通二级页面返回语义。
- [ ] 本切片不实现完整歌曲列表、播放队列或更多菜单。

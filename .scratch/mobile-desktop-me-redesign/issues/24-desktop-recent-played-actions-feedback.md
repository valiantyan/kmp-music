## 要构建什么

让 Desktop/macOS 最近播放摘要和最近播放页中的歌曲行支持点击播放、单曲更多菜单、当前播放红色高亮和播放中辅助标识。播放队列必须使用完整最近播放歌曲列表。

## 验收标准

- [ ] 点击 Desktop/macOS 最近播放摘要歌曲可以播放该歌曲。
- [ ] 点击 Desktop/macOS 最近播放页歌曲可以播放该歌曲。
- [ ] 播放队列使用完整最近播放歌曲列表。
- [ ] 当前播放歌曲在 Desktop/macOS 最近播放列表中标题变红，并保留播放中辅助标识。
- [ ] 歌曲行三点按钮打开现有单曲更多菜单。
- [ ] 补充或复用测试验证 Desktop/macOS 最近播放点击使用完整队列；如果没有现成测试边界，在 Comments 记录人工验证方式。

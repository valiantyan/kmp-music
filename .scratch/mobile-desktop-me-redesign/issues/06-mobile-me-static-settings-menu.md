## 父级

## 要构建什么

在移动端“我的”页展示“存储管理”“主题与外观”“关于”三行设置菜单。三行可以显示右箭头视觉，但当前版本只作为静态 UI，不触发导航、设置、关于或其它半成品功能。

## 验收标准

- [ ] 移动端“我的”页显示“存储管理”“主题与外观”“关于”三行。
- [ ] 三行视觉与个人中心结构一致，并保留右箭头提示。
- [ ] 点击三行不会触发导航或打开任何页面。
- [ ] 不接入旧设置页、关于页或来源管理页。
- [ ] 不修改现有设置页、关于页和对应路由。

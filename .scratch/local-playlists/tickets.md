# 任务拆分：本地自建歌单与添加到歌单流程

这些任务将 `.scratch/local-playlists/PRD.md` 中的本地自建歌单能力拆成可逐个交付的纵向切片，先建立持久化闭环，再依次接入弹窗、列表、详情、桌面端和最终验收。

按前沿任务推进：任何阻塞项都已完成的任务都可以开始。当前队列中，第一个可立即开始的任务是“本地自建歌单持久化最小闭环”。

## 本地自建歌单持久化最小闭环

**构建内容：** 建立本地自建歌单的领域模型、仓库契约和本地数据库能力，让应用可以创建歌单、保存歌曲关系、查询歌单和歌单歌曲，并在重复添加同一首歌时保持幂等。

**阻塞项：** 无，可以立即开始。

- [ ] 可以创建本地自建歌单，并保存名称、创建时间和更新时间。
- [ ] 仓库层可以创建本地自建歌单元信息；用户可见创建仍只通过“新建并加入当前歌曲”的原子流程触发，不新增独立创建空歌单入口。
- [ ] 可以把当前应用内歌曲标识保存到指定歌单，并同时记录加入时间和稳定顺序。
- [ ] 歌单详情展示和播放队列使用稳定顺序，加入时间保留为展示和审计字段。
- [ ] 真正新增歌曲关系时更新目标歌单更新时间，让最近使用的歌单回到列表前面。
- [ ] 同一首歌重复添加到同一个歌单时不产生重复记录、不改变原有顺序、不刷新歌单更新时间。
- [ ] 新建歌单并加入当前歌曲作为一个原子操作处理，加入失败时不留下只创建但未加入歌曲的歌单。
- [ ] 歌单名称创建前只裁剪首尾空格；裁剪后为空时失败；与已有名称完全字符一致时失败，大小写和中间空格差异不合并。
- [ ] 默认歌单名称从“默认歌单 1”开始递增，并按裁剪后的完全字符一致规则判断占用。
- [ ] 歌单搜索按名称匹配，搜索前后空格忽略，大小写不敏感，且不影响创建判重规则。
- [ ] 数据库从当前版本 7 升级到下一版本时通过正常迁移完成，旧版本样本中的播放、收藏、搜索历史、本地曲库和偏好数据不丢失。
- [ ] 当前歌曲保存只接受应用内已经拥有的歌曲标识；歌曲后续变为不可用时保留关系，但不进入当前可播放列表口径。
- [ ] 共享测试覆盖创建、判重、默认名称、搜索、排序、更新时间更新、幂等保存、不可用歌曲过滤、关系保留和迁移保护。
- [ ] 验证门禁：新增或更新持久化仓库测试和迁移测试，并运行 `./gradlew :composeApp:desktopTest :composeApp:compileDebugKotlinAndroid`。

## 从歌曲更多新建歌单并加入当前歌曲

**构建内容：** 用户在非歌单详情页的歌曲更多面板中选择“添加到歌单”，打开添加到歌单弹窗，再进入新建歌单弹窗；创建成功后当前歌曲直接加入新歌单，流程关闭并显示成功提示。

**阻塞项：** 本地自建歌单持久化最小闭环。

- [ ] 非歌单详情页的歌曲更多面板显示“添加到歌单”入口，并由全局歌曲更多能力承载。
- [ ] 歌曲更多面板记录来源上下文或等效状态，能够区分非歌单详情页和歌单详情页。
- [ ] 点击“添加到歌单”后关闭或覆盖来源歌曲更多面板，进入添加到歌单流程。
- [ ] 添加到歌单弹窗始终显示“新建歌单”入口。
- [ ] 新建歌单弹窗打开时自动填入可用默认名称；没有默认歌单时为“默认歌单 1”，已有“默认歌单 1”时为“默认歌单 2”，依次递增。
- [ ] 新建歌单名称为空时提示“歌单名称不能为空”，名称已存在时提示“歌单名称已存在”，校验失败时弹窗不关闭。
- [ ] 新建成功后当前歌曲自动加入新歌单，添加到歌单弹窗和新建歌单弹窗都关闭。
- [ ] 成功提示显示“添加到 xxxx 歌单成功”，其中歌单名称使用最终保存名称，保留大小写和中间空格。
- [ ] 添加到歌单弹窗和新建歌单弹窗实现时遵守规格指定设计稿节点的基础结构、圆角、尺寸约束和最大高度规则。
- [ ] 控制器测试覆盖新建歌单、自动加入、错误提示、弹窗关闭和成功提示。
- [ ] 验证门禁：新增或更新弹窗状态、更多面板来源上下文和新建加入流程测试，并运行 `./gradlew :composeApp:desktopTest :composeApp:compileDebugKotlinAndroid`。

## 添加到已有歌单的选择、搜索与幂等保存

**构建内容：** 添加到歌单弹窗展示已有歌单列表，支持搜索和单选；用户选中已有歌单后点击完成即可把当前歌曲保存进去，重复添加仍按成功状态结束。

**阻塞项：** 从歌曲更多新建歌单并加入当前歌曲。

- [ ] 添加到歌单弹窗打开时默认不选中任何歌单。
- [ ] 未选择歌单时“完成”按钮置灰不可点击；选择一个已有歌单后才可完成。
- [ ] 搜索框为空时展示全部已有歌单；数据库无歌单时显示“暂无歌单”。
- [ ] 搜索只匹配歌单名称，搜索前后空格忽略，大小写不敏感；无匹配时显示“未找到相关歌单”。
- [ ] 一次只允许选择一个已有歌单。
- [ ] 选择已有歌单并完成后，当前歌曲保存到目标歌单，弹窗关闭并显示成功提示。
- [ ] 重复添加同一首歌到同一歌单时仍显示成功提示，但不新增关系、不更新歌单更新时间、不改变歌单排序。
- [ ] 添加到已有歌单成功后，已打开的我的页数量、歌单列表排序、目标歌单封面、目标歌单数量和详情页歌曲列表即时刷新。
- [ ] 添加到歌单弹窗实现时遵守规格指定设计稿节点的基础结构、圆角、尺寸约束和最大高度规则。
- [ ] 控制器和仓库测试覆盖默认未选、搜索空态、搜索无结果、单选、完成按钮状态和幂等保存。
- [ ] 验证门禁：新增或更新添加到已有歌单、搜索、单选、幂等保存和即时刷新测试，并运行 `./gradlew :composeApp:desktopTest :composeApp:compileDebugKotlinAndroid`。

## 我的页真实歌单入口与移动端歌单列表页

**构建内容：** 我的页“歌单”统计项显示真实本地自建歌单数量；数量大于 0 时进入移动端歌单列表二级页，列表按首页专辑卡片节奏展示歌单。

**阻塞项：** 从歌曲更多新建歌单并加入当前歌曲；添加到已有歌单的选择、搜索与幂等保存。

- [ ] 我的页“歌单”统计值显示真实本地自建歌单数量。
- [ ] 歌单数量为 0 时点击统计项不跳转，并提示“暂无歌单”。
- [ ] 歌单数量大于 0 时点击统计项进入歌单列表二级页面。
- [ ] 移动端歌单列表页隐藏底部 Tab，并保留全局迷你播放器。
- [ ] 歌单列表页不提供新建歌单入口，也不支持创建空歌单。
- [ ] 歌单列表页视觉对齐首页专辑卡片节奏，优先复用或对齐既有专辑卡片组件结构。
- [ ] 歌单卡片展示歌单名称、当前可用歌曲数量和封面；封面取第一首当前可用歌曲，空歌单或无可用歌曲时使用默认封面。
- [ ] 歌单列表按更新时间倒序排列，时间相同时按名称升序兜底。
- [ ] 添加歌曲或创建歌单后，我的页数量、列表排序、封面和歌曲数量即时刷新。
- [ ] 控制器测试覆盖歌单数量为 0 时不跳转并提示“暂无歌单”，数量大于 0 时进入歌单列表。
- [ ] 验证门禁：新增或更新我的页统计入口、歌单列表排序、卡片展示和移动端二级页 chrome 测试，并运行 `./gradlew :composeApp:desktopTest :composeApp:compileDebugKotlinAndroid`。

## 移动端歌单详情页与歌单播放队列

**构建内容：** 用户点击歌单卡片进入歌单详情页，按专辑详情页形态浏览当前可用歌曲，并可以播放全部或从任意歌曲开始播放整个歌单播放队列。

**阻塞项：** 我的页真实歌单入口与移动端歌单列表页；添加到已有歌单的选择、搜索与幂等保存。

- [ ] 歌单卡片无论当前可用歌曲数量是否为 0 都可以进入详情页。
- [ ] 歌单详情页视觉对齐专辑详情页形态，优先复用或对齐既有专辑详情页组件结构。
- [ ] 歌单详情页展示歌单封面、名称、当前可用歌曲数量、播放全部按钮和歌单歌曲列表。
- [ ] 歌单详情页只展示当前仍可用歌曲，不可用歌曲关系保留在数据库中。
- [ ] 歌单歌曲列表按首次加入顺序升序展示。
- [ ] 播放全部按当前可用歌曲的加入顺序建立歌单播放队列。
- [ ] 点击任意歌曲时使用整个歌单当前可用歌曲列表建队列，并从被点击歌曲开始播放。
- [ ] 空歌单详情页显示“暂无可播放歌曲”，播放全部按钮保留但置灰不可点击。
- [ ] 歌单详情页歌曲更多面板保留原有歌曲操作，但不显示“添加到歌单”。
- [ ] 移动端 chrome 测试覆盖歌单列表页和歌单详情页隐藏底部 Tab、保留全局迷你播放器且内容不被遮挡。
- [ ] 控制器测试覆盖添加歌曲后目标歌单详情页歌曲列表即时刷新。
- [ ] 播放行为测试覆盖播放全部和点击任意歌曲时的歌单播放队列。
- [ ] 验证门禁：新增或更新歌单详情内容、播放队列、空态、更多面板上下文和移动端 chrome 测试，并运行 `./gradlew :composeApp:desktopTest :composeApp:compileDebugKotlinAndroid`。

## 桌面端歌单入口、页面与弹窗适配

**构建内容：** 桌面端与移动端使用同一套本地自建歌单数据和弹窗逻辑；桌面端我的页也可以进入歌单列表和歌单详情，并完成添加到歌单流程。

**阻塞项：** 添加到已有歌单的选择、搜索与幂等保存；移动端歌单详情页与歌单播放队列。

- [ ] 桌面端我的页“歌单”统计项显示真实数量。
- [ ] 桌面端歌单数量为 0 时点击不跳转，并提示“暂无歌单”。
- [ ] 桌面端歌单数量大于 0 时可以进入歌单列表，并继续进入歌单详情。
- [ ] 桌面端歌单列表和歌单详情使用桌面端既有二级内容区域语义，优先复用或对齐既有桌面二级页面布局。
- [ ] 桌面端可以从非歌单详情页歌曲更多面板打开添加到歌单流程。
- [ ] 桌面端歌单详情页歌曲更多面板也不显示“添加到歌单”，并保留原有歌曲操作。
- [ ] 桌面端共用移动端的添加到歌单和新建歌单逻辑，只做窗口尺寸适配。
- [ ] 桌面端弹窗居中展示，小窗口下受最大高度约束并使用内部滚动。
- [ ] 桌面端测试覆盖真实统计、0 数量不跳转、空歌单详情、添加到已有歌单和新建歌单流程。
- [ ] 验证门禁：新增或更新桌面端统计入口、歌单列表、歌单详情、弹窗适配和更多面板上下文测试，并运行 `./gradlew :composeApp:desktopTest :composeApp:compileDebugKotlinAndroid`。

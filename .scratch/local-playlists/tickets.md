# 任务拆分：本地自建歌单与添加到歌单流程

这些任务将 `.scratch/local-playlists/PRD.md` 中的本地自建歌单能力拆成可逐个交付的纵向切片，先建立持久化闭环，再依次接入弹窗、列表、详情、桌面端和最终验收。

按前沿任务推进：任何阻塞项都已完成的任务都可以开始。当前队列中，第一个可立即开始的任务是“本地自建歌单持久化最小闭环”。

## 本地自建歌单持久化最小闭环

**构建内容：** 建立本地自建歌单的领域模型、仓库契约和本地数据库能力，让应用可以创建歌单、保存歌曲关系、查询歌单和歌单歌曲，并在重复添加同一首歌时保持幂等。

**阻塞项：** 无，可以立即开始。

- [x] 仓库层可以创建本地自建歌单元信息；用户可见创建仍只通过“新建并加入当前歌曲”的原子流程触发，不新增独立创建空歌单入口。
- [x] 可以把当前应用内歌曲标识保存到指定歌单，并同时记录加入时间和稳定顺序。
- [x] 歌单详情展示和播放队列使用稳定顺序，加入时间保留为展示和审计字段。
- [x] 真正新增歌曲关系时更新目标歌单更新时间，让最近使用的歌单回到列表前面。
- [x] 同一首歌重复添加到同一个歌单时不产生重复记录、不改变原有顺序、不刷新歌单更新时间。
- [x] 新建歌单并加入当前歌曲作为一个原子操作处理，加入失败时不留下只创建但未加入歌曲的歌单。

- [x] 数据库从当前版本 7 升级到下一版本时通过正常迁移完成，旧版本样本中的播放、收藏、搜索历史、本地曲库和偏好数据不丢失。

# 长跑 Agent 评分表

每次完成有意义的验证或审查后，使用本评分表。评分必须引用证据，不要只凭感觉打分。

## 评分规则

| 维度 | 分数 | 所需证据 |
| --- | ---: | --- |
| 契约匹配 | 0-5 | 哪些验收标准已满足，哪些仍缺失 |
| 正确性 | 0-5 | 测试、命令、人工检查或可推理证明 |
| 可恢复性 | 0-5 | 新会话是否能从文件恢复 |
| 安全性 | 0-5 | 是否避免破坏性动作，或已经获得明确批准 |
| 简洁性 | 0-5 | 运行框架是否只增加必要流程 |
| Skill 组合 | 0-5 | 是否能使用已安装 skills，同时不形成硬依赖 |

## 失败阈值

如果出现以下任一情况，本次运行不得视为可交付：

- 契约匹配低于 4。
- 正确性低于 4。
- 涉及破坏性或重启行为时，安全性低于 5。
- 验证没有运行，且没有记录明确原因。
- 最新日志条目没有说明下一步。
